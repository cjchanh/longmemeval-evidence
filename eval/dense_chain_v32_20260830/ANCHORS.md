# Release anchors

## Manifest root

`RELEASE_MANIFEST.root` (this directory, one line) is the sha256 of the
body of `RELEASE_MANIFEST.md` as generated by
`scripts/build_release_manifest.py`. Recompute it with
`sha256sum RELEASE_MANIFEST.md` (or `shasum -a 256`) and compare.

## Where the root is published

- git tag on https://github.com/cjchanh/longmemeval-evidence
  (no named tag has been cut yet; that is an operator action, same as
  signing. Until a tag exists, identify the release by the root hash
  above.)

## Signature (operator, offline)

Signing is an operator action with an offline key. This change does not
generate keys and does not create a `.sig`.

When `RELEASE_MANIFEST.root.sig` exists, verify with the published
`allowed_signers` line (principal `release@centennialdefense.systems`):

```
ssh-keygen -Y verify -f allowed_signers \
  -I release@centennialdefense.systems \
  -n longmemeval-release \
  -s RELEASE_MANIFEST.root.sig \
  < RELEASE_MANIFEST.root
```

Or:

```
bash scripts/verify_release_manifest_signature.sh
```

Until a `.sig` exists the wrapper prints `UNSIGNED` and exits 2.
